FRONTEND SEKRETARIAT DPRD PURBALINGGA

Cara menjalankan:
1. Ekstrak folder.
2. Buka index.html di browser.
3. Untuk hasil terbaik, jalankan dengan Live Server di VS Code.

Hosting:
- Bisa diunggah langsung ke Netlify (drag & drop folder).
- Bisa diunggah ke GitHub Pages.
- Bisa diunggah ke Vercel sebagai static site.

Catatan:
- Data dokumen, kontak, dan statistik masih berupa data demo.
- Tombol unduh, form kontak, pencarian global, dan video perlu disambungkan ke backend/API saat tahap berikutnya.
- Folder design-reference berisi screenshot desain asli sebagai acuan.
